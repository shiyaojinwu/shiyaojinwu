# 旅游 AI 助手：从问答开始认识工具调用

[← 返回主页 · 作品存档](../README.md#-作品存档)

**个人练手 · AI 辅助实现 · Java / Spring AI**

这是我最早的个人 AI 练手项目，基本借助 AI 完成，架构比较简单。我以旅游问答为入口，学习多轮记忆、RAG、工具调用和 MCP，逐步弄清楚一条消息怎样经过检索、模型和工具，再回到对话中。

<details>
<summary><b>让问答记住上下文，也能参考资料</b></summary>

项目使用 Java 21、Spring Boot 和 Spring AI，按会话 ID 保存多轮记忆，并接入流式回答与结构化游玩报告。围绕同一个目的地连续提问，是我理解会话历史如何参与后续回答的起点。

RAG 部分接入 PGVector，通过向量检索取回相关片段，再补入生成上下文。我从这里开始区分“模型知道什么”和“这次检索给了什么”，也学习检索数量、相似度阈值怎样影响回答所依据的材料。

</details>

<details>
<summary><b>从生成回答，到调用工具</b></summary>

工具调用部分让模型选择本地工具或 MCP 工具，由工具管理器执行，再把结果写回会话历史，供下一步判断使用；流程也提供了终止工具。

这段练习帮助我理解工具的描述、参数、执行结果和结束条件怎样串起来。目前的实现以简单的思考与执行循环为主。完整演示与回答质量还需要继续验证，后续也想补上工具失败时的处理和固定问题回归。

</details>

这些入门经验后来在心屿中继续发展，再延续到现在的 Mindhaven。
